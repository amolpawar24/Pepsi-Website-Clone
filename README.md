# 🥤 Pepsi Website Clone

A modern and responsive **Pepsi website clone** built using **HTML, CSS, and JavaScript**.

This project recreates a Pepsi-inspired landing page with a responsive navigation bar, animated product switching, promotional sections, videos, social links, and a modern visual experience.

## 🎯 Main Sections

### 🧭 Navbar

The navigation section contains links for:

* Home
* Products
* What's New
* Newsletter
* Contact

It also includes a responsive menu for smaller screen sizes.

### 🏠 Home Section

The hero section contains:

* Pepsi branding
* Main heading
* Description
* Product CTA
* Product image
* Social media links
* Interactive product thumbnails

The product thumbnails allow users to switch between different Pepsi products.

### 🥤 Product Slider

Users can click on the product images to dynamically change:

* Main product image
* Background color

Example:

```javascript
imgSlider('./ASSETS/pepsi002.png');
changeBgColor('#e60c2c');
```

### 🖤 Zero Sugar Section

A dedicated section for highlighting Pepsi Zero Sugar content and branding.

### 🎬 Products Section

Contains promotional video content and Pepsi product-focused visuals.

### 🎥 Gallery Section

Includes a fullscreen-style promotional video section with Pepsi branding.

## 📱 Responsive Design

The website is designed to work across different screen sizes:

```text
Desktop
   ↓
Laptop
   ↓
Tablet
   ↓
Mobile
```

The layout adapts to smaller screens with responsive navigation, content positioning, images, and video sections.

---

## ⚙️ JavaScript Functionality

The website uses JavaScript for interactive functionality such as:

```javascript
menuToggle();
imgSlider();
changeBgColor();
```

These functions control the responsive navigation menu, product image switching, and dynamic background colors.

## 💻 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/pepsi-website-clone.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd pepsi-website-clone
```

### 3. Run the website

Open:

```text
index.html
```

in your browser.

For the best development experience, you can use **VS Code with the Live Server extension**.
